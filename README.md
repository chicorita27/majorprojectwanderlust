# Wanderlust 🗺️

A full-stack travel platform that allows users to explore, create, and review destinations — built using the MERN stack. It features geolocation mapping, image uploads, and secure user authentication to deliver a complete travel experience.

---

## 🚀 Features

- 🧭 Explore and search travel destinations.
- 📝 Create, edit, and delete destination entries.
- 🌍 Interactive maps using **Mapbox** for location visualization.
- 🖼️ Upload destination images via **Cloudinary**.
- 🔐 User authentication and authorization using **Passport.js**.
- 💾 RESTful API with full CRUD functionality.
- 🌐 Fully responsive frontend with **React.js** and **EJS** templating.
- ☁️ Hosted on **Render**.

---

## 🛠️ Tech Stack

**Frontend:**
- React.js
- EJS
- TailwindCSS (optional)

**Backend:**
- Node.js
- Express.js

**Database:**
- MongoDB
- Mongoose

**Other Tools:**
- Passport.js (Auth)
- Mapbox (Maps)
- Cloudinary (Image uploads)
- Render (Deployment)
